# 오늘의 한 방 ⚾

설치할 의존성이 없는 터치 야구 게임입니다. Python 3와 최신 브라우저로 실행합니다.

```sh
npm run dev
```

3000번 포트에서 실행됩니다. 시작 버튼을 누른 다음 공이 홈플레이트에 도착할 때 화면을 터치하거나 Space를 누르세요. 타이밍 바의 초록 구간이 타격 시점입니다. 매 투구마다 공의 위치가 달라지고, 타격 타이밍과 배트 중심으로부터의 거리가 비거리를 결정합니다. 최고 기록은 브라우저에 저장됩니다.

```sh
npm test
```

외부 서비스나 API 키가 필요하지 않습니다. Google Fonts에 연결할 수 없으면 시스템 글꼴로 표시됩니다.
