# 오늘의 한 방 ⚾ — Low Poly 3D

터치 한 번으로 즐기는 로우폴리 3D 야구 게임입니다. 투수와 타자는 관절을 가진 입체 메시로 구성되며, 3D 배트·공·구장·그림자와 타격 효과를 사용합니다. 홈플레이트 뒤의 포수 시점에서 중앙의 투수와 스트라이크존을 바라보며, 타자는 화면 왼쪽에 표시됩니다.

## 실행

VS Code에서 이 폴더를 열고 **Live Server** 확장을 설치한 뒤 `index.html` 우클릭 → **Open with Live Server**를 선택하세요. 별도 패키지 설치나 API 키가 필요하지 않습니다. `file://`로 직접 열지 마세요.

Python 3이 있다면 `npm run dev` 또는 `python3 -m http.server 3000`도 사용할 수 있습니다. 브라우저에서 WebGL 2와 하드웨어 가속이 필요합니다. 최신 Chrome, Edge, Firefox, Safari를 권장합니다.

## 조작

플레이 시작 후 공이 스트라이크존에 도착할 때 화면을 터치하거나 Space를 누르세요. 매 투구마다 공의 위치가 달라지며 타이밍과 배트 중심으로부터의 거리로 비거리가 결정됩니다. 최고 기록은 브라우저에 저장됩니다. 120m 이상이면 장타 효과와 추가 효과음이 나옵니다. 모바일도 지원합니다.

## 검증

Node.js가 있다면 `npm test`로 비거리 및 타격 동작 관련 테스트를 실행합니다.

Three.js 0.180.0은 MIT 라이선스로 `vendor/three`에 포함했습니다. CDN 연결이나 npm 설치 없이 3D 게임이 실행됩니다. 글꼴도 시스템 글꼴을 사용하므로 실행 중 외부 네트워크 연결이 필요하지 않습니다.

85m 이상 좋은 타격에는 공을 따라가는 항공뷰가 적용됩니다. 착지 지점 표시와 비거리를 확인한 뒤 다음 공을 시작하면 포수 시점으로 복귀합니다. 동작 줄이기 설정에서는 이동하는 추적 카메라 대신 고정 항공뷰를 사용합니다.

다음 공은 포수 시점으로의 복귀가 끝난 뒤 0.65초의 준비 시간을 거쳐 시작합니다. 화면 복귀와 준비 중에는 투구 및 스윙 판정이 진행되지 않습니다.

## 화면과 효과

구장에는 전광판·외야 광고판·조명탑이 있으며, 최근 타격의 비거리·타이밍 정확도·중심 적중률을 화면 아래에서 확인할 수 있습니다. 최고 기록을 갱신하면 알림이 표시됩니다. 오른쪽 위의 소리 ON/OFF 버튼으로 효과음을 조절하며 설정은 브라우저에 저장됩니다. 동작 줄이기 설정에서는 타격 화면의 번쩍임과 팝업 애니메이션을 줄입니다.
